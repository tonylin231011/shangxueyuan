# Changelog

## v1.0 — 课程首次归档

- 整理第一局星巴克2008经营转型模拟资料。
- 分离历史事实、当时可知信息、模拟创作和AI推演。
- 保留玩家原始指令和模拟时间线。
- 记录内部模拟报表、顾客调查、门店调查、财务数据与培训试点。
- 记录资源结算不一致、指标口径和图表错误。
- 明确模拟局尚未完成最终战略决策和历史棋谱复盘。
- 新增供其他AI独立审阅的结构化任务书。

### 已知限制

- 部分历史来源需要继续核对页码及更精确段落。
- 当前模拟中的大部分内部数据为课堂创作，尚未建立可计算、可重复运行的状态转移引擎。
- 本局资源结算存在不一致，已在规则和棋谱中显式保留。
- 经营方向的最终决策与真实历史对照尚未完成。
