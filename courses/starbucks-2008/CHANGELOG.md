# Changelog

## v1.1 — 审计与引擎设计

- 新增 `audit-findings-v1.1.md`，将问题分为P0/P1/P2，并给出可验收修复要求。
- 新增 `engine-design-v1.1.md`，定义历史事实层、玩家信息层、世界状态层、事件账本和呈现层。
- 明确历史日期、模拟时钟、史料公开时间与玩家可见时间必须分离。
- 明确角色历史任职事实与模拟角色场景分离。
- 规定状态变化必须通过事件账本；资源、日历时间和组织执行能力分别结算。
- 设计证据质量字段、NPC触发规则、分支快照和回放机制。
- 新增10项首批自动化验收测试。
- 使用SEC FY2007 10-K、2008年1月7日SEC公告及1月7日/11日员工信核验核心历史指标与领导职务，并修正Martin Coles任职时间边界的审计表述。
- 为关键历史数据补充可定位的SEC网页行号范围，明确公司整体同店指标与美国业务交易趋势不可混用。
- 保留V1.0全部原始棋谱与已知错误，不静默修正。

### V1.1 状态声明

本版本完成的是档案审计和引擎设计规范，不代表模拟引擎代码已经实现，也不代表历史资料已完成逐页史料审计。

## v1.0 — 课程首次归档

- 整理第一局星巴克2008经营转型模拟资料。
- 分离历史事实、当时可知信息、模拟创作和AI推演。
- 保留玩家原始指令和模拟时间线。
- 记录内部模拟报表、顾客调查、门店调查、财务数据与培训试点。
- 记录资源结算不一致、指标口径和图表错误。
- 明确模拟局尚未完成最终战略决策和历史棋谱复盘。
- 新增供其他AI独立审阅的结构化任务书。

### 已知限制

- 部分历史来源需要继续核对页码及更精确段落。
- 当前模拟中的大部分内部数据为课堂创作，尚未建立可计算、可重复运行的状态转移引擎。
- 本局资源结算存在不一致，已在规则和棋谱中显式保留。
- 经营方向的最终决策与真实历史对照尚未完成。
