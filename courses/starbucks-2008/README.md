# 商业残局 01｜星巴克：增长、体验与扩张的冲突

> 原始模拟归档：v1.0  
> 审计与引擎设计：v1.1  
> 规则引擎与历史棋谱fixture：v1.2（独立开发分支）  
> 状态：模拟推进至2008-01-20；最终战略决策和历史复盘待完成

## 课程定位

本课程不是星巴克2008年经营史的完整重演，也不是对其真实内部决策过程的复刻。它以公开历史背景为舞台，构建一个由玩家担任CEO的互动经营模拟。玩家在有限时间、信息和决策资源下调查经营异常、决定行动，并观察模拟团队执行后的反馈。

本课训练重点：

- 从增长指标中识别经营质量变化；
- 区分相关性、因果关系与待验证假设；
- 在信息不完整时选择调查顺序；
- 平衡顾客体验、产品复杂度、门店效率和扩张回报；
- 记录决策理由，并用后续证据检验判断。

## 当前版本状态

V1.0保留原始玩家指令、模拟结果和已知缺陷。V1.1新增审计结论与引擎设计。V1.2在独立分支实现规则注册表、回填V1.0棋谱fixture，并补齐数据口径和史实开局材料。

V1.2规则引擎通过预登记函数计算状态变化，具备确定性回放、指数基期检查、证据设计分级、NPC触发评估日志和策略分支测试；**它不是完整模拟器**，尚未实现完整NPC规划、历史信息发布门控、完整任务排程或经真实经营数据校准的状态模型。

本局已推进至模拟时间2008-01-20。玩家尚未完成向董事会的最终经营方向陈述，也尚未进行历史结果对照复盘。因此不把本局称为完整结课，不给玩家决策打分，也不替玩家补写最终决策。

## 重要标签

- **H｜历史事实**：来自公开历史材料，需保留出处。
- **K｜当时可知信息**：假设在模拟时点可由管理团队获得；如无直接史料支持，需标明为模拟情境。
- **S｜模拟创作**：本课程为互动而生成的内部数据、管理层对话、门店样本、访谈、资源数值和事件。
- **I｜AI推演**：根据玩家指令和模拟规则生成的因果链或后果，不等同于真实历史。
- **U｜未核实**：目前无法可靠归类或验证的信息。

## 重要免责声明

本局中出现的顾客指数、门店分组、运营试点、财务指标、内部邮件、管理层对话、访谈摘录、区域调查样本、资源数值、顾客满意度和运营改善结果，均属于 **S｜模拟创作**，不可作为星巴克真实经营数据或真实内部会议记录引用。历史事实与公开资料应以 historical-record.md 中的可核验来源为准。

本归档中的模拟设定不应反向作为历史证据。
